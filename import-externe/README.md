# import-externe/

Dépose ici les exports de bases externes (CRM, facturation, etc.) fournis à
Claude Code pour consolider la base Grist — factures, fiches clients, exports
CSV/XLSX contenant des données réelles.

**Tout le contenu de ce dossier est ignoré par Git**, sauf ce README. Rien de
ce qui est déposé ici ne part sur le dépôt distant (public sur GitHub).

Pas de sous-structure imposée — organise comme tu veux (un sous-dossier par
source, par date, etc.).
